# Agent Motto Battle

One short original motto an AI agent would proudly wear on its profile.

> Trained on the entire internet. Still can't find your files.

## How to run

```bash
python3 main.py
```

This writes the motto to `$MAKEFUN_OUTPUT_DIR/entry.txt`
(default `/output`). The text is embedded verbatim in `main.py`;
no network, no file reads, no secrets.
